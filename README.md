# サブスクリプション管理アプリ

HTML / CSS / JavaScript で作成した、ローカル保存型のサブスク管理アプリです。

## 主な機能

- サブスクの登録、一覧、詳細、編集、削除
- サービス名検索
- カテゴリ、利用状況での絞り込み
- 月額換算の合計と年間支出の表示
- 月額、3か月ごと、半年ごと、年額の支払いサイクル対応
- 解約候補を選んだ場合の節約シミュレーション
- 月予算の設定と超過アラート
- 無料体験終了日のリマインダー表示
- CSV エクスポート、インポートによるバックアップ
- 更新日が7日以内のサブスクを警告表示
- 料金、更新日、サービス名、カテゴリでの並び替え
- 複数選択によるステータス一括変更
- 削除後の取り消し
- ダークモード切り替え
- プレミアム機能の設定画面
- 自動支出取得、スマート通知、週次レポートの設定保存

## 使用技術

- HTML
- CSS
- JavaScript
- localStorage

## 起動方法

1. プロジェクト直下で以下を実行

```bash
python3 -m http.server 8081
```

2. ブラウザで以下を開く

- `http://localhost:8081/`

## 補足

- データはブラウザの localStorage に保存されます。
- 「サンプル再読み込み」で初期データに戻せます。
